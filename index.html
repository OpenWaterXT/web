Ranking oficial en vivo

La web de IPC Services bloquea la carga dentro de cuadros/iframe: por eso aparece el icono de prohibido. Esta versión elimina el visor y usa el sistema correcto: lectura mediante conector API.

Modo directo real: despliega el paquete en Vercel y pulsa “Leer ranking en directo”. El HTML llamará a /api/wps-ranking, que lee IPC Services desde servidor y devuelve datos importables.

Si estás abriendo el archivo como HTML local, puede no funcionar por CORS. Para directo real usa el ZIP de Vercel incluido. El iframe ya no se usa porque IPC Services no permite mostrarse dentro del cuadro blanco.

Qué hace el conector

El conector intenta leer la ruta pública de rankings de IPC Services desde servidor, parsear tablas/HTML/JSON y devolver filas normalizadas.

Fuente objetivo: https://www.ipc-services.org/sdms/public/rankings/swm Respuesta esperada por el HTML: { "ok": true, "count": 123, "data": [ { "athlete": "Name Surname", "npc": "ESP", "gender": "Men", "event": "50 m Freestyle", "class": "S9", "time": "25.10", "date": "2026-03-02", "competition": "Competition name", "rank": 1, "points": 987 } ] }

Si IPC Services devuelve 403 o cambia su estructura interna, habrá que ajustar el extractor del archivo api/wps-ranking.js. No hay forma limpia de saltarse X-Frame/CORS solo con HTML local.

Importar marcas/rankings

Pega CSV/TSV o carga un archivo .csv/.tsv/.txt/.xlsx. El sistema importa automáticamente al seleccionar el archivo, detecta cabeceras, conserva atleta/país/marca y valida la clase para evitar errores tipo S50.
